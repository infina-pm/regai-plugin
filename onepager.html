How it works

Scrape → index → retrieve — deterministically

An LLM agent drives a small set of read-only tools over the corpus. The legal reasoning itself is deterministic — no model decides the law at query time.

1
vbpl.vn → vault

Ingest

Scrape official legislation, following in-force legal relations — a Luật pulls in its implementing Nghị định / Thông tư.

2
vault → index

Build

Index the corpus for full-text search, hosted centrally and kept current.

3
index → answer

Retrieve

The agent queries 6 read-only tools, follows the regulation chain, verifies in-force status, and cites sources.

The corpus is hosted centrally and kept current — nothing to download or build.
