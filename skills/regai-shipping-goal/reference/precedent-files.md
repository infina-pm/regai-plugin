# Reference: working with uploaded precedent files

A mission may come with precedent files (past legal situations, opinions) the user
uploads — Word/PDF, sometimes 20+. Read them with the `docx` / `pdf` skills. Don't
read all of them blindly; index, select, extract.

## 1. Index (when there are several)

Skim each file and build a table before reading any in depth:

```
| # | Tên file | Vấn đề pháp lý | Lĩnh vực | Kết quả xử lý | Mức rủi ro |
```

If it's unclear which matter, ask: *"Em đã lập index — anh muốn tham chiếu tình huống
nào, hay để em tự chọn file liên quan nhất?"*

## 2. Select

Read in depth **only** files with high relevance to the current matter — same lĩnh
vực, same issue type (BCC, nhận tiền gửi, dữ liệu…), or same regulator. State which
files you skipped and why ("không tham chiếu file X — không liên quan").

## 3. Extract (per selected file)

```
📁 [tên file]
- Vấn đề | Văn bản áp dụng | Hướng xử lý đã dùng | Kết quả | Điểm tương đồng với câu hỏi hiện tại
```

## Limits

- **Don't extrapolate** beyond the file. If it's thin, say so.
- If a precedent cites a văn bản that is now expired, **re-verify via `check_in_force`**
  and apply the in-force successor — a precedent's law can have moved on.
- An old outcome is not a guarantee if the legal context has changed.
